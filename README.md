# 🌾 Smart Crop Yield Prediction System

An AI-powered **Smart Crop Yield Prediction System** developed using Machine Learning and Streamlit. This application predicts crop productivity based on agricultural and environmental parameters such as rainfall, temperature, pesticide usage, year, area, and crop type.

The system provides an interactive web interface that helps users estimate crop productivity using a trained Decision Tree Regression model.

## 🚀 Project Overview

Agriculture plays an important role in economic development. Crop productivity depends on several factors, including climate conditions, soil-related parameters, and agricultural inputs.

This project uses Machine Learning to analyze these parameters and predict crop productivity. It provides a simple and user-friendly interface where users can enter agricultural details and obtain an estimated crop yield.

## ✨ Features

- 🌱 Interactive and user-friendly Streamlit interface.
- 🌧️ Average rainfall input.

## 🤖 Machine Learning Algorithm

**Decision Tree Regressor**

The project uses a Decision Tree Regression algorithm to predict crop productivity based on the provided input parameters.

### Input Parameters

1. Year
2. Average rainfall (mm/year)
3. Pesticides usage (tonnes)
4. Average temperature (°C)
5. Area (Country)
6. Crop (Item)

### Output

Predicted crop productivity in:

**Hectograms per hectare (hg/ha)**

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/Smart-Crop-Yield-Prediction.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Smart-Crop-Yield-Prediction
```

### Step 3: Install Required Dependencies

```bash
pip install -r requirements.txt
```

Alternatively:

```bash
pip install streamlit numpy pandas scikit-learn plotly
```

### Step 4: Run the Application

```bash
streamlit run app.py
```

### Step 5: Open in Browser

Streamlit will automatically open the application in your browser.

Default local URL:

```text
http://localhost:8501
```

## 📊 Application Workflow

1. User enters agricultural and environmental parameters.
2. Input data is converted into the required format.
3. The preprocessing pipeline transforms the input data.
4. The trained Decision Tree Regressor processes the transformed data.
5. The system generates predicted crop productivity.
6. Results are displayed through an interactive dashboard.
7. Users can download the prediction report as a CSV file.
